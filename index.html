Tasks 5, 11 & 12

GitHub Pages Deployment

  1. Push all project files to GitHub.
  2. Open repository Settings → Pages.
  3. Select Deploy from a branch.
  4. Select the main branch.
  5. Select /(root).
  6. Click Save.
  7. Wait for GitHub Pages to deploy.
  8. Open the published website.
  9. Test every page and link.
  10. Take a screenshot of successful deployment.
